# 极简Vibe Coding需求文档生成器

## 项目概述
提供一份极简且AI友好的需求说明，用于指导开发一个带AI分析的雅思写作练习网站。

## 核心功能
1. 题库与练习：支持雅思Task1/Task2题目列表、随机抽题、计时写作与字数统计。
2. AI评分与反馈：调用大模型生成分项评分（TR/CC/LR/GRA）与可操作改进建议。
3. 范文与对比：展示官方范文或高分示例，并支持与用户稿件的对比提示。
4. 进度与档案：保存作文历史、评分、版本，提供按题型/分数的统计视图。
5. 分享与导出（可选）：导出PDF/Markdown，生成可分享链接或截图。

## 技术要求
- 技术栈：前端Next.js/React，后端Node.js（Express或Next API Routes），大模型调用（OpenAI API兼容接口），样式Tailwind CSS。
- 平台：Web（桌面+移动端响应式）。
- 关键依赖：Markdown编辑/渲染组件、代码高亮/差异对比库（如diff算法）、持久化数据库（PostgreSQL或Supabase）。

## 用户体验
- 目标用户：准备雅思写作的考生，偏高效练习与反馈。
- 交互方式：文本编辑器+实时辅助信息；评分结果与改进建议分块展示；历史记录列表+详情。
- 设计风格：现代、极简、暗浅主题可切换，移动端友好。

## 数据与状态
- 数据模型：用户、作文（题目、Task类型、正文、字数、用时、版本）、评分（四项子分与总分）、范文资源、练习统计。
- 持久化：关系型数据库（PostgreSQL/Supabase），对象存储用于导出文件或截图。
- 状态管理：前端使用React Query/SWR处理数据获取与缓存，支持乐观更新与错误回退。

## 关键约束
- 性能要求：核心交互<200ms响应；AI评分请求队列/重试；页面首屏TTI<3s（含缓存）。
- 安全要求：用户鉴权（JWT/Session）；API限流与输入校验；日志脱敏；防止提示词注入。
- 兼容性要求：Chrome/Edge/Safari最新版；移动端视口适配。
- 其他限制：AI提示与评分逻辑可配置，预留模型/供应商切换；记录版本并可追溯。

## 实现建议
- 前端：富文本或Markdown编辑器，自动保存草稿；组件按Task类型配置模板；使用可插拔评分卡组件。
- 后端：统一AI服务封装（可切换模型/路由）；评分提示词模板化；队列或后台任务处理长时AI请求。
- 监控：埋点记录写作时长、评分耗时、错误率；A/B测试范文与反馈样式。

## 验收标准
- 用户可选择或随机抽取Task1/Task2题目，计时写作并保存稿件与字数/用时。
- AI可返回总分+四项分数及针对性改进建议，响应失败有可视提示并可重试。
- 用户可查看历史记录、评分趋势，查看范文/示例并与自己的稿件对比或导出。
